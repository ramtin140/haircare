# Hair Care Routine Webapp - Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep Forest Green (#1B4332) - representing natural hair growth and health
- **Secondary**: Warm Cream (#F8F5F0) - clean, medical, premium feel
- **Accent**: Soft Gold (#D4AF37) - luxury and premium hair care
- **Text**: Charcoal (#2D3748) - excellent readability with Persian text

### Typography
- **Display Font**: "Vazirmatn" - elegant Persian font for headings and titles
- **Body Font**: "Inter" - clean, modern sans-serif for body text and UI elements
- **Persian Text**: Proper RTL support with beautiful Persian calligraphy aesthetics

### Visual Language
- **Minimalist Luxury**: Clean, spacious layouts with premium feel
- **Wellness Aesthetic**: Calming, health-focused visual elements
- **Persian Elegance**: Subtle cultural elements integrated seamlessly
- **Medical Precision**: Clean, organized presentation of health information

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth animations for routine completion and progress tracking
- **ECharts.js**: Beautiful progress visualization and statistics
- **Typed.js**: Typewriter effects for Persian text introductions
- **Splitting.js**: Letter-by-letter animations for headings
- **p5.js**: Subtle particle effects and background animations
- **Splide.js**: Elegant image carousels for treatment visualization

### Animation Effects
- **Text Animations**: 
  - Typewriter effect for main headings in Persian
  - Staggered letter animations for routine items
  - Smooth fade-ins for daily tasks
- **Interactive Elements**:
  - Gentle hover effects on clickable items
  - Smooth transitions between routine states
  - Celebration animations for completed tasks
- **Background Effects**:
  - Subtle particle system representing hair follicles
  - Gentle gradient animations
  - Soft floating elements for wellness ambiance

### Header Effect
- **Aurora Gradient Flow**: Soft, flowing background gradient
- **Floating Particles**: Subtle animated elements suggesting hair growth
- **Typography Animation**: Large Persian headings with typewriter effect
- **Hero Image**: Generated abstract hair care aesthetic image

### Layout & Styling
- **Grid System**: Clean, organized layout for routine items
- **Card Design**: Elevated cards for each treatment with soft shadows
- **Color Coding**: Different treatments with subtle color variations
- **Progress Indicators**: Animated progress bars and completion states
- **Responsive Design**: Mobile-first approach for daily use

### Persian Text Integration
- **RTL Layout**: Proper right-to-left text flow
- **Font Optimization**: Beautiful Persian typography with proper spacing
- **Cultural Sensitivity**: Respectful integration of Persian language elements
- **Accessibility**: High contrast text for readability

## Interactive Components Styling
- **Daily Tracker**: Clean checkbox design with smooth animations
- **Timer Interface**: Elegant countdown displays with Persian text
- **Calendar View**: Beautiful weekly grid with hover effects
- **Progress Charts**: Sophisticated data visualization with Persian labels
